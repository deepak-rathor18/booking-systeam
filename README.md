# Meeting Room Booking System

A web application to manage meeting rooms and bookings.

## Tech Stack
- Frontend: React, TypeScript, Vite
- Backend: Node.js, Express.js
- Database: MySQL

## Features
- View meeting rooms and bookings
- Book a meeting room
- Cancel bookings
- Check room availability

## Installation & Setup

### Frontend
```bash
npm install
npm run dev
```

### Backend
```bash
npm install
npm run dev
```

Configure your MySQL database credentials in the backend `.env` file before starting the server.

## Backend URL
`http://localhost:3000`
